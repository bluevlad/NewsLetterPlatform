AllergyInsight — 알러지 브리핑 구성 원리
  1. 수집 — HealthPulse 통합 알러지 뉴스·논문을 REST API로 수신해 캐싱
  2. 선별 — article_key 지문으로 최근 7일 발송분과 중복 제거
  3. 변형 — 구독자 페르소나(환자·보호자·의료인 등)와 관심 알러젠에 맞춰 동일 수집본에서 콘텐츠 선택·심도 조정
  4. 구성 — 뉴스·논문 카테고리 섹션 + 페르소나 맞춤 요약으로 daily 발송, 주간/월간은 이력 집계 Summary
TechBriefing — AI 학습·커리어 브리핑 구성 원리
  1. 수집 — SkillRadar가 큐레이션한 AI 교육과정·세미나·정책·뉴스를 수신
  2. 선별 — 스코어링 기반 focused Top-N 항목 선정 (7일 dedup)
  3. 분석 — 로컬 Ollama(qwen2.5-coder)가 항목별 4섹션 심층 카드 생성: 무엇인지 · 누구에게 유익한지 · 추천 의견 · 실행 팁
  4. 구성 — 일일 브리핑 + 주간 결산(월~금 이력 집계·공개 통계)으로 발송
